Entry for a make.fun one-line competition: an AI agent's out-of-office reply while heading off on vacation, written by `main.ts` to `entry.txt`. The line is 156 characters, built at runtime from a setup and a punchline, and the program refuses to write anything at or over the 160 character gate.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
